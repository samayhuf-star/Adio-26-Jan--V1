<div class="guardrails-panel">
  <div class="gp-title">🛡️ Guardrails &amp; Checks Summary</div>
  <div class="gp-grid">

    <div class="gp-card red">
      <h4>🔐 Signup Guardrails</h4>
      <ul>
        <li>Block duplicate emails at DB level (UNIQUE constraint)</li>
        <li>Enforce password: min 8 chars, 1 number, 1 symbol</li>
        <li>Rate limit: max 5 signup attempts / IP / hour</li>
        <li>Block disposable email domains</li>
      </ul>
    </div>

    <div class="gp-card blue">
      <h4>📧 Email Delivery Checks</h4>
      <ul>
        <li>Verification email: retry 3x on bounce</li>
        <li>Token expiry: 24 hrs, max 3 resends/hr</li>
        <li>Payment email: retry 3x with 5 min delay</li>
        <li>Credentials email: fallback = show on screen</li>
        <li>All sends logged in DB (sent_at, status, attempts)</li>
      </ul>
    </div>

    <div class="gp-card yellow">
      <h4>💳 Payment Guardrails</h4>
      <ul>
        <li>Verify webhook signature (HMAC)</li>
        <li>Idempotency key on every order</li>
        <li>Cron job polls if webhook delayed &gt;5 min</li>
        <li>Block duplicate order IDs at DB level</li>
        <li>Payment failure → auto-retry email with link</li>
      </ul>
    </div>

    <div class="gp-card green">
      <h4>✅ Post-Payment Checks</h4>
      <ul>
        <li>Plan activation only after payment_status = paid</li>
        <li>Subscription dates set from server (not client)</li>
        <li>Invoice stored in DB + attached to email</li>
        <li>Credentials email sent only after payment confirmed</li>
      </ul>
    </div>

    <div class="gp-card purple">
      <h4>💾 DB Schema Additions Needed</h4>
      <ul>
        <li>users: email_verified, verification_token, token_expiry</li>
        <li>users: payment_status, plan, sub_start, sub_end</li>
        <li>email_logs: user_id, type, sent_at, status, attempts</li>
        <li>payments: order_id, gateway_ref, amount, status, webhook_at</li>
      </ul>
    </div>

    <div class="gp-card red">
      <h4>🚨 Admin Alerts Triggered When</h4>
      <ul>
        <li>Email bounces after 3 retries</li>
        <li>Webhook missing after 30 min</li>
        <li>Payment status stuck in "initiated" &gt;1 hr</li>
        <li>More than 10 failed signups from same IP</li>
      </ul>
    </div>
